# Simple Recipes

A beginner-friendly HTML and CSS website for the Simple-Recipes assignment.

## Features
- Navigation bar with a hover/focus dropdown menu
- Smooth scrolling to page sections
- Featured recipe and recipe cards
- CSS image hover transformations
- About section above the contact form
- Responsive layout for mobile and desktop
- Google Fonts typography

## How to open
Open `index.html` in a browser, or open the folder in Visual Studio Code and use Live Server.

Recipe photos load from Unsplash and Google Fonts load from Google Fonts, so an internet connection is needed for those external assets.

The contact form is a front-end demonstration and does not send messages to a server.
