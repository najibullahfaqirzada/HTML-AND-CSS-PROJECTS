# The Tech Academy — HTML and CSS Projects

This repository contains my coursework and practice projects completed while learning foundational web development skills through The Tech Academy. Each project is organized in its own folder with its related files and assets.

## Projects

### 1. Academy Cinemas
A cinema-themed website created to practice HTML structure, navigation, movie listings, website layout, and Bootstrap styling.

### 2. Basic HTML and CSS
A collection of introductory exercises covering HTML elements, document structure, CSS selectors, properties, and basic website styling.

### 3. Creating CSS Effects
Practice exercises focused on visual presentation and interactive styling using CSS effects and hover interactions.

### 4. Simple Recipes
A recipe website created to practice headings, paragraphs, links, images, content organization, and CSS styling.

### 5. The Pet Shop Website
A themed website project focused on organizing information and presenting content using HTML and CSS.

### 6. Personal Portfolio
A separate portfolio website showcasing my introduction, web development learning journey, and selected projects. It uses HTML and CSS, a coding image, a typing video, responsive styling, and a personalized color palette.

## Technologies and Skills

- HTML5 — page structure and content
- CSS3 — styling, layout, and hover effects
- Bootstrap — styling and layout in Academy Cinemas
- Images and video — multimedia assets
- GitHub — version control, source-code hosting, and project sharing
- Responsive design — adapting website layouts to different screen sizes

## How to View the Projects

Open a project's HTML file in a web browser when available. Keep each project's stylesheet, images, videos, and other assets in their original folder structure so the pages can load correctly.
