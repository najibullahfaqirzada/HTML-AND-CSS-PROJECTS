# Academy Cinemas

A single-page Bootstrap 5 project recreated from the supplied course screenshots.

## Files
- `index.html`: navbar, homepage hero, movie listings, ticket form, contact form, and footer
- `style.css`: layout and cinema theme styling
- `movies.txt`: movie descriptions and credits supplied for the assignment
- `images/`: the seven provided Academy Cinemas image assets

## Preview
Open `index.html` in a browser. Bootstrap and Google Fonts load from online CDNs, so an internet connection is needed for those resources.

The ticket and contact forms demonstrate front-end interactions only; they do not process payments or send email.
